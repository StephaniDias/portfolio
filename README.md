# 💻 Portfólio | Stephani Dias

Bem-vindo(a) ao meu portfólio! 👋

Este projeto foi desenvolvido para apresentar um pouco sobre minha trajetória profissional, minhas habilidades, conhecimentos e projetos desenvolvidos durante minha jornada de aprendizado na área de Tecnologia da Informação.

## 👩‍💻 Sobre mim

Sou estudante de **Análise e Desenvolvimento de Sistemas** e estou em busca de uma oportunidade de **estágio em Tecnologia da Informação**, onde possa aplicar meus conhecimentos, aprender na prática e continuar desenvolvendo minhas habilidades profissionais.

Possuo conhecimentos em desenvolvimento web e tecnologias voltadas à criação de interfaces, além de experiência profissional com atendimento, suporte operacional, análise de dados e resolução de problemas.

## 📂 Projetos apresentados

Alguns dos projetos disponíveis no portfólio:

### 🧮 Calculadora de IMC

Aplicação desenvolvida para calcular o Índice de Massa Corporal (IMC) a partir das informações fornecidas pelo usuário.

### 🍔 Landing Page de Hamburgueria

Projeto de uma página web para uma hamburgueria, desenvolvido com foco em layout, organização visual e experiência do usuário.

### 🎁 Amigo Secreto

Aplicação desenvolvida em JavaScript que permite adicionar participantes e realizar o sorteio de um amigo secreto.

### ✅ Lista de Tarefas

Aplicação para organização de tarefas, permitindo praticar conceitos de manipulação do DOM e JavaScript.

### ✈️ Tela de Login para Site de Viagens

Interface de login desenvolvida com foco em design, estruturação de página e estilização com CSS.

### 💻 Site de Tecnologia

Projeto voltado à criação de uma interface para apresentação de conteúdos relacionados à tecnologia.
